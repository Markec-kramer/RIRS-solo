RIRS-solo

Člani ekipe: Marko Kramer

Kratek opis projekta

Projekt je spletna aplikacija, ki prikazuje oglase (listings), omogoča filtriranje in razvrščanje ter uporablja Prisma ORM za delo z bazo (SQLite).

CI/CD

  • Build + cache + artefakti
  • Gradnja Docker slike in objava na Docker Hub
  • Deploy na Render
  • GitHub Pages stran za opis projekta
